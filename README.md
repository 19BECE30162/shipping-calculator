# Shipping Calculator

A simple command-line Python application that calculates shipping costs using a package's weight and a shipping rate per kilogram.

## Features

- Accepts package weight in kilograms.
- Accepts a shipping rate per kilogram.
- Calculates the shipping cost.
- Displays the result in USD.

## Requirements

- Python 3.8 or later

## Run locally

1. Clone or download this repository.
2. Open a terminal in the project directory.
3. Run:

   ```bash
   python Shipping_Cost_Calculator.py
   ```

## Example

```text
Enter the package weight in kilograms: 10
Enter the shipping rate per kilogram: 5
Shipping Cost: 50.0 USD
```

## Formula

`Shipping cost = package weight (kg) × shipping rate (USD/kg)`

## Project status

This is an educational starter application. It intentionally demonstrates a basic calculation and does not yet include production features such as input validation, carrier integrations, taxes, dimensional weight, or delivery-time estimates.
