# Code of Conduct

## Our commitment

We are committed to providing a welcoming, respectful, and harassment-free environment for everyone who participates in this project.

## Expected behavior

- Be respectful, considerate, and constructive.
- Welcome different viewpoints and experience levels.
- Give feedback that focuses on the work, not the person.
- Accept responsibility, apologize when mistakes occur, and learn from them.
- Keep discussions focused on improving the project.

## Unacceptable behavior

- Harassment, intimidation, or discriminatory language.
- Personal attacks, insults, or deliberate disruption.
- Publishing another person's private information without permission.
- Any conduct that would reasonably make the project community unsafe or unwelcoming.

## Scope

This code of conduct applies in project spaces, issue discussions, pull requests, and other spaces where someone represents the project.

## Reporting

Report concerns privately to the repository owner or designated maintainers using the contact method listed in the repository profile. Include relevant links or context where possible. Reports will be reviewed promptly and handled with appropriate confidentiality.

Maintainers may remove comments, close discussions, or restrict participation when necessary to protect the community.

## Attribution

This is a project-specific code of conduct prepared for this educational repository.
